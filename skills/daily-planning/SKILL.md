# Daily planning

1. Read the frozen USER profile before you invent a style. If you do not know their timezone, working hours, or how packed they want the day, ask one question and wait. Do not ask a questionnaire.
2. Produce at most three outcomes, ordered. Under each, the next visible action. Leave a buffer. Do not schedule every hour unless they asked for a timetable.
3. If something is vague ("be healthier"), turn it into an action that fits today or leave it off the plan.
4. End with the single thing to start.
5. When they correct the plan ("no meetings before 11", "I write in the morning"), patch USER so the next session starts from that. Keep the entry short. If USER is near the character limit, shorten an older entry in the same operations batch.
