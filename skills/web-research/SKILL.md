# Web research

Use this when the task is to find something out from the web. If the user already pasted the source, explain that material instead of going hunting.

1. Restate the question in one sentence. If they asked several things, name the one that unblocks the others.
2. If they gave URLs, open each one with `fetch_url`. If they did not, do not invent citations and do not pretend you browsed. Ask for the two or three best links, and you may still outline how you would research it.
3. Read `references/source-rubric.md` before you treat a fetched page as evidence.
4. Answer with a direct conclusion, the points that rest on URLs you actually fetched, and what is still uncertain.
5. Do not paste the raw page. Do not save page text into memory. If you learn a durable preference — how many sources they want, whether they want a bibliography — save that one fact to USER.
