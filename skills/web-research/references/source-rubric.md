# Source rubric

Use this before you lean on a fetched page.

- Who is speaking, and can they know this? A vendor page is a claim about their product, not an independent measurement.
- What date is on the page? If you cannot find one, say the page is undated.
- Is this the thing itself (a spec, a filing, a paper) or a retelling? Prefer the thing itself when both are available.
- Separate what the page says from what you are inferring. Label the inference.
- One page is not a consensus. If the sources disagree, say so in a sentence. Do not average them into a false middle.
- If `fetch_url` failed or was truncated, the missing part is unknown. Do not fill it from memory of the public web.
